# dsh-oneway-usage-monitor

在 DSH Web 右下角以**悬浮指标卡片**展示 [ONE-WAY 中台](https://oneway.eportyun.com/)（oneway.eportyun.com）的 Token 用量：

- **近 5 小时**（绿）：最近 5 小时的 Token 用量
- **今日**（蓝）：今日累计 Token 用量
- **本周**（紫）：本周累计 Token 用量

卡片逐行显示**颜色标签 + 数值**，悬停显示本周占比百分比；点击卡片打开详情弹窗。

## 功能

| 能力 | 说明 |
|---|---|
| 悬浮指标卡片 | 右下角常驻；三行（近5小时 / 今日 / 本周）色点 + 标签 + Token 数值，悬停显示占比 |
| 详情弹窗 | 顶部常驻「Token 用量（含占比进度条）+ Token/请求/时长 KPI」摘要，下方 4 个标签页：请求日志 / 用量趋势 / 渠道用量·限额 / 渠道与模型 |
| 企业微信扫码登录 | 直接在插件内展示二维码扫码登录，无需手动粘贴 Cookie；会话保存在本机 DSH 设置 |
| 自动刷新 | 默认每 120 秒刷新一次（可配置 30–3600 秒），与站内「每 2 分钟自动刷新」一致 |
| 请求日志 | 按日期范围查询（默认近 7 天），支持分页，展示时间/模型/所属 Key/渠道/状态/流式/延迟/Token |
| 用量趋势 | 最近 24 小时每小时、最近 30 天每日的请求数与 Token 分布条 |
| 按渠道用量/限额 | 渠道 × (近 5 小时 / 5h 限额 / 今日 / 本周 / 周限额 / 本月 / 本年)，有限额时显示进度条 |
| 渠道与模型 | 分组展示每个渠道可用的模型列表 |
| 设置页 | `设置 → 插件 → OneWay 用量`：网关地址、刷新间隔、悬浮窗开关、本周参考值自定义 |

## 数据来源与口径

- 站点为**服务端渲染**页面（无公开 JSON API）：插件 Host 端直接抓取 `/my-usage`、`/my-requests` 并解析 HTML，归一化为 JSON 后经同源接口提供给 Web 客户端，不经过任何第三方。
- **占比以「本周用量」为参考**：本周恒为 100%，今日占比 = 今日 ÷ 本周，近 5 小时占比 = 近 5 小时 ÷ 本周，一眼看出本周进度与最近活跃度；可在设置页把参考值改为固定 Token 数（>0 生效）。本周为 0 时回退用本月用量作参考。
- 「Token 用量 / 请求次数 / 使用时长」五档统计（近 5 小时 / 今日 / 本周 / 本月 / 本年）与站内「个人信息」页完全一致。

## 安装

在**本仓库根目录**执行：

```bash
dsh plugin --profile web add ./dsh-oneway-usage-monitor
```

安装后**重启 DSH Web Host 一次**以装载 profile bundle，然后刷新浏览器页面。

> ⚠️ 重启会结束当前所有运行中的会话，请先保存工作进度。

### 首次使用

1. 点击右下角指标卡片（未登录时标题显示「点击登录」）→ 打开详情弹窗并进入扫码页。
2. 用企业微信扫码并确认，网关会话 Cookie 由 DSH Host 保存在本机设置文件中（`role('secret')`，不会经任何网络传输）。
3. 登录成功后卡片三行分别显示近 5 小时 / 今日 / 本周的 Token 用量。

## 安全说明

- 会话 Cookie **只保存在本机** DSH 设置文件，仅由 DSH Host 用于请求 oneway.eportyun.com 页面；插件接口只允许 `127.0.0.1` 同源访问，写操作需要一次性授权令牌。
- Host 不存储、不导出、不转发任何请求体/响应体给第三方；页面抓取只发生在 DSH 进程内。
- 退出登录会清除本机保存的会话 Cookie。

## 开发与验证

```bash
pnpm install --ignore-scripts

# 校验插件结构
node ./scripts/validate.mjs

# 语法检查
node --check ./index.js
node --check ./client.js

# 生成界面预览原型（复用 client.js 中的样式，示例数据）
node ./scripts/build-preview.mjs
```

界面预览原型位于 `examples/preview.html`，用浏览器直接打开即可（含已登录 / 未登录 / 空数据三种状态与标签页切换，数据均为示例标注）。

## 已知限制

- 站点无 CORS 头且无公开 JSON API，依赖对服务端渲染 HTML 的解析；若站点改版导致解析失败，插件会在弹窗中显示「页面结构变化」类错误，需要同步更新 `index.js` 中的解析规则。
- 扫码登录依赖企业微信 SSO 页面结构（`web_key` / `getWebQrCodeStatus`），若微信侧改版同样需要跟进。
- 「今日 / 本周」等统计边界以网关服务器时区为准，容量推算使用本机时区，跨时区场景下容量百分比可能略有偏差。
